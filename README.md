
# ImagineYourCraftDatapack
Attempt to recreate Minecraft's ImagineYourCraft mod with an advanced Datapack, for Minecraft 26.3.

[FEATURES.md](FEATURES.md) lists every block, item and mechanic of the original mod and what the datapack does with it.

## Build
```bash
uv sync
uv run stewbeet
```
The datapack and resource pack zips land in `build/`, the `_with_libs` ones bundling the libraries.
`assets/original` holds the blockstates, models and textures taken from the mod's jar, converted into 26.3 models at build time.
